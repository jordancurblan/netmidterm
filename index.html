Fix These First (missed on the last exam)

  • Preamble is 7 bytes (not bits). The 8th byte is the SFD = 10101011.
  • MAC address = 48 bits = 6 hex pairs. First 3 pairs = OUI (vendor).
  • IPv4 address = 32 bits = 4 octets / hex pairs (not 3).
  • PDUs: L4 = Segment (TCP) / Datagram (UDP), L3 = Packet, L2 = Frame, L1 = Bits.
  • Port 23 = Telnet · 88 = Kerberos · 137 = NetBIOS Name Service · 161 = SNMP.
  • ARP = Address Resolution Protocol · FCS = Frame Check Sequence · OUI = Organizationally Unique Identifier · PDU = Protocol Data Unit · SFD = Start Frame Delimiter · MAC = Media Access Control.
  • Capture vs display filter: capture filter decides what gets recorded; display filter only hides/shows what was already captured.
  • Subnet ID must land on a block-size boundary: 172.16.200.187/19 → 172.16.192.0, not 172.16.200.0.
  • MTU length = total frame length − 14 (Ethernet header). 60 − 14 = 46.
  • EtherType for IPv4 is 0x0800 (4 hex digits), IPv6 0x86DD, ARP 0x0806.

  • Header = Dest MAC + Src MAC + EtherType = 14 bytes.
  • Minimum frame = 64 bytes · Maximum frame = 1518 bytes (preamble/SFD not counted).
  • SFD binary = 10101011 (ends in 11 to say "frame starts now").
  • EtherType is 16 bits: 0x0800 IPv4 · 0x86DD IPv6 · 0x0806 ARP.
  • FCS = CRC error check at the end of the frame.
  • MAC = 48 bits, 6 hex pairs, e.g. 00:1A:2B:3C:4D:5E → OUI = 00:1A:2B.
  • Broadcast MAC = ff:ff:ff:ff:ff:ff (ARP requests go here).

TCP vs UDP

TCP

Connection-oriented, 3-way handshake (SYN → SYN/ACK → ACK), reliable, ordered, retransmits. Flags: SYN, ACK, FIN, RST, PSH, URG.

UDP

Connectionless, no handshake, no guarantees, low overhead and fast. Used by DNS, DHCP, TFTP, NTP, SNMP, streaming/VoIP.

Bits on12345678
Octet128192224240248252254255
Block size1286432168421

Formulas

  • # subnets = 2borrowed bits (borrowed = new prefix − default prefix)
  • # hosts per subnet = 2host bits − 2 (host bits = 32 − prefix)
  • Block size = 256 − the interesting mask octet

Method: given IP + prefix

  1. Class from 1st octet.
  2. Write the mask; find the interesting octet (the one that isn't 255 or 0).
  3. Block size = 256 − that octet.
  4. Subnet ID = biggest multiple of the block size ≤ the IP's value in that octet. Octets after it become 0.
  5. Broadcast = next subnet ID − 1. Octets after it become 255.

Method: "Need X subnets"

  1. Find the smallest n where 2n ≥ X.
  2. New prefix = default prefix + n.
  3. Then run the method above on the given IP.
Powers of 2: 28=256 · 210=1,024 · 211=2,048 · 212=4,096 · 213=8,192 · 214=16,384 · 215=32,768 · 216=65,536 · 217=131,072 · 218=262,144
"Location (3rd subnet, 5th host)": list subnet IDs by block size from the start of the network, pick the 3rd, then add 5 to it. Example: 192.168.25.0/28 → subnets .0, .16, .32 → 3rd subnet = .32, 5th host = 192.168.25.37. If your instructor skips the zero subnet, start counting at .16 instead, so ask which convention they use.

Packet Breakdown Cheat Sheet

ARP

EtherType 0x0806. Request goes to broadcast ff:ff:ff:ff:ff:ff; reply is unicast. Opcode 1 = request, 2 = reply. Gratuitous ARP = announcing your own IP.

IPv4 header

Min 20 bytes. Protocol field: 1 = ICMP, 6 = TCP, 17 = UDP. TTL drops by 1 per router hop.

ICMP

Type 8 = Echo Request (ping), Type 0 = Echo Reply. Type 3 = Destination Unreachable, Type 11 = Time Exceeded.

DHCP (UDP 67/68)

Option 53 message types: 1 Discover, 2 Offer, 3 Request, 5 ACK (DORA).
Lengths: MTU length = total frame length − 14. Example: 60-byte frame → 46.

IPv6 Addressing

  • IPv4 = 32 bits, dotted decimal (8.8.8.8). IPv6 = 128 bits, 8 hextets of 4 hex digits.
  • Shortening: drop leading zeros in a hextet (0db8 → db8); replace one run of all-zero hextets with :: (only once).
  • Example: 2001:0db8:85a3:0000:0000:8a2e:0370:7334 → 2001:db8:85a3::8a2e:370:7334
  • Standard split: /64 network prefix + 64-bit interface (host) ID.
  • NAT exists in IPv4 because addresses ran out; IPv6 has enough to skip it.

NDP / ICMPv6

NDP does the Layer 3 → Layer 2 resolution (ARP's job) using multicast instead of broadcast.

TypeMessageWhat it does
133Router Solicitation (RS)Host asks "any routers here?"
134Router Advertisement (RA)Router says "I'm here" + prefix info. All-nodes multicast; Cisco sends every 200 s by default. Used by SLAAC.
135Neighbor Solicitation (NS)Find the MAC for a known IPv6 address (like ARP request). Also used for DAD.
136Neighbor Advertisement (NA)Unicast reply with the MAC (like ARP reply).
137RedirectRouter points host to a better next hop.
Memory trick: Router pair first (133 RS, 134 RA), then Neighbor pair (135 NS, 136 NA), then Redirect (137). Solicitation = ask, Advertisement = answer.

SLAAC & DHCPv6

  • Every IPv6 node needs a GUA to talk outside its local segment.
  • Stateful = DHCP server tracks addresses. Stateless = no server tracking.
  • SLAAC does NOT provide DNS.

RA flags tell the host what to do

FlagMeaningMethod
A flagHost can auto-generate its own GUASLAAC
O flagGet DNS server list + domain name from a stateless DHCPv6 server, not the addressStateless DHCPv6 (SLAAC + DHCP for DNS)
M flagGet address (GUA) and DNS from a DHCPv6 serverStateful DHCPv6

In stateful DHCPv6, the host still sets its default gateway from the RA.

SLAAC steps

  1. Node configures itself with a link-local address.
  2. Node runs DAD.
  3. Node sends an RS; router replies with an RA.
  4. Node combines the RA prefix with its interface ID to build its IPv6 address.
  5. Run DAD again.

Stateless logic: generate address → run DAD → repeat until DAD is clean.

Virtualization & Cloud

Hypervisor = software that controls how physical resources (CPU, RAM, storage) are shared between VMs.

Type 1 (bare metal)

Runs directly on hardware. Used in data centers, server environments, enterprise. Examples: VMware ESXi, Microsoft Hyper-V, Proxmox.

Type 2 (hosted)

Runs inside another OS as an app. Examples: VirtualBox, Parallels, VMware Workstation.

Scaling

  • Vertical = add resources to the same machine (more RAM/CPU).
  • Horizontal = add more machines.

Security & Networking Basics

Networking

  • LAN = local area (one building/campus). WAN = connects LANs over large distances (the internet is the biggest WAN).
  • IEEE standards: 802.3 = Ethernet, 802.11 = Wi-Fi. Wi-Fi 7 = 802.11be. Cat6 = up to 10 Gbps at ~55 m (1 Gbps at 100 m).
  • MAC = Layer 2 physical address · IP = Layer 3 logical address · Ports = Layer 4.

Cybersecurity

CIA Triad

Confidentiality (only authorized eyes) · Integrity (data not altered) · Availability (accessible when needed)

Threat / Vulnerability / Risk

Threat = what could cause harm · Vulnerability = weakness that can be exploited · Risk = likelihood × impact of a threat hitting a vulnerability

Malware

Any malicious software (ransomware, trojans, spyware, viruses, worms).

Virus vs Worm

Virus attaches to a file and needs a user to run it. Worm self-replicates and spreads across the network on its own.

Social Engineering

Manipulating people instead of systems. Phishing = fake emails/sites to steal credentials.

Hashing

One-way function → fixed-length output. Same input = same hash. Used for integrity checks and password storage. Examples: SHA-256 (MD5 is outdated).

MFA: the 4 factors

Something you know (password) · have (phone/token) · are (fingerprint) · somewhere you are (location). MFA = 2+ different categories.
